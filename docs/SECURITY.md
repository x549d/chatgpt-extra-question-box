# 安全与数据处理

5I 后升级备份和恢复使用 SQLite Backup API，源库在迁移前备份，包含已提交 WAL；回滚失败保留当前用户 backups 目录中的恢复副本。受控环境权限拒绝不通过提权或修改 ACL 绕过。发行 ZIP 仅包含运行载荷和用户文档，逐文件哈希、发布物 SHA256SUMS 与源码提交记录由独立审计脚本核对。

应用通过官方 App Server stdio 协议复用官方登录状态。没有 Cookie 读取、内存 Token 提取、OAuth 绕过、配对码收集或认证凭据落库逻辑。App Server 位于空工作目录，使用 read-only sandbox、禁止审批的策略与现有工具请求拒绝逻辑；子进程由 Win32 Job Object 管理。

SQLite 参数绑定避免搜索字符串拼接为 SQL；外键、唯一键、事务、WAL、FULL 同步、版本与完整性检查保护数据一致性。数据库没有应用层加密。备份同样含个人对话，默认仅在当前 Windows 用户目录。磁盘内容的物理擦除、操作系统备份和 Codex 自身 session 文件不由本项目的软删除控制。

Markdown 不执行 HTML、脚本或图片请求。仅允许用户点击 HTTP(S) 链接，复制使用原始文本。日志不得包含完整问答或底层异常中可能携带的凭据。Git 提交前用 gitleaks 扫描；扫描通过不能代替审查。

安装仅调用官方插件 CLI，仅移除本插件的 marketplace、缓存和自有快捷方式；历史默认保留。正式公开交付前必须确认许可证、发布者隐私联系信息、可信签名，以及在干净 Windows 环境完成安装/升级/卸载测试。
