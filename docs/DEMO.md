# 操作演示与界面说明 / Walkthrough & Demo

本文档详细介绍 **Context Notes Native** 在 Windows 版 **Codex Desktop（Chat 模式）** 中的 6 个核心交互场景、界面元素、快捷键与核验方式。

> **关于真实截图的隐私与真实性说明**：为严格遵守隐私原则（不截取维护者真实日常对话或生产 SQLite 历史数据库），并遵守开源真实性原则（**不使用伪造 UI 或概念图冒充真实软件截图**），本仓库当前仅提供基于真实软件行为编写的交互演示文档。维护者在空白/示例对话中完成脱敏截屏后，将直接按第 7 节规范补充真实 PNG 截图至 `docs/assets/`。

---

## 1. 选区浮动「提问」按钮（Selection Entry）

1. 打开 Windows 版 **Codex Desktop**，确认当前处于 **Chat 模式**。
2. 在**助手回答**区域内用鼠标划选任意一段文字或代码块。
3. 选区旁立即出现一个不抢焦点的浮动 **「提问」** 按钮（底层使用 `WS_EX_NOACTIVATE` + `WM_MOUSEACTIVATE` 拦截）：
   - 不会打断当前阅读位置或滚动状态；
   - 不会改写或占用 Windows 系统剪贴板；
   - 默认优先显示在选区右侧顶端，空间不足时自动回退至左侧、下方或上方，并主动避让底部聊天输入框；
   - 选中用户自己的提问或输入框草稿时不会误触发。

```text
+---------------------------------------------------------------+
| Codex Desktop (Chat Mode)                                     |
|                                                               |
| Assistant:                                                    |
|   "SQLite WAL mode allows concurrent readers while..."        |
|    [=========== 鼠标划选的片段 ===========]  +------+         |
|                                              | 提问 |  <-- WS_EX_NOACTIVATE
|                                              +------+         |
+---------------------------------------------------------------+
```

---

## 2. 选区旁独立旁注小框（Inline Annotation Window）

点击浮动 **「提问」** 按钮后，在选区旁立即弹出独立的旁注小框（`AnnotationWindow`）：

- **自动聚焦输入框**：打开后即可直接输入中文（完整支持 IME 组合输入）或英文问题，无需二次点击。
- **独立窗口定位**：支持拖动调整位置，Codex 窗口移动时自动跟随偏移，并始终限制在可见显示器工作区内（支持多显示器与混合 DPI 缩放）。
- **轻量窗口操作**：支持折叠/展开整个旁注窗口、随时点击关闭而不影响其他已打开的旁注。

---

## 3. 原文引用区（Verbatim Quote）

旁注窗口顶部自动固定展示被划选的原文片段：

- **逐字符原样保留**：完整保留连续空格、代码缩进、全角标点与原始换行结构。
- **一键折叠/展开**：当引用的代码块较长时，可点击折叠引用区以腾出更多回答阅读空间；折叠不会丢失任何引用文本。

---

## 4. AI 实时流式回答与停止生成（Streaming Response）

在旁注输入框输入追问并按 `Enter`（`Shift+Enter` 换行）：

1. 后台通过本机官方 `codex.exe app-server`（stdio JSON-RPC 2.0）为该旁注建立独立 `ThreadId` 并发送引用上下文与追问。
2. 回答区域以增量流式方式实时渲染 Markdown 内容：
   - 标题、列表、粗体/斜体、行内代码与围栏代码块清晰排版；
   - 代码块支持原样一键复制与折叠；
   - 仅允许安全的 `http://` / `https://` 链接打开，屏蔽潜在危险协议。
3. 生成过程中可随时点击 **「停止」** 按钮发送 `turn/interrupt` 立即中断服务端输出。
4. 可点击 **「模型与用量」** 查看当前账号可用模型列表与限额快照，并按需切换默认模型或当前旁注模型。

```text
+--------------------------------------------------+
| 旁注 #1  [模型: 默认]  [历史]  [折叠]  [关闭]     |
+--------------------------------------------------+
| > 引用原文（可折叠）                              |
|   SQLite WAL mode allows concurrent readers...   |
+--------------------------------------------------+
| 你：WAL 模式在崩溃恢复时如何保证数据一致性？      |
|                                                  |
| 助手（流式输出中...）：                           |
|   在 WAL 模式下，写入先追加到 `-wal` 日志文件，    |
|   只有在提交帧校验通过后才对新读事务可见……        |
|   ```sql                                [复制]   |
|   PRAGMA journal_mode=WAL;                       |
|   ```                                            |
+--------------------------------------------------+
| [输入追问，Enter 发送 / Shift+Enter 换行] [停止]  |
+--------------------------------------------------+
```

## 5. 多旁注并发与连续追问（Multi-Annotation Concurrency）

- **同一旁注多轮追问**：在同一旁注窗口内继续输入新问题，上下文自动沿用该旁注专属 `ThreadId`。
- **多旁注独立并发**：在主聊天页的不同段落连续划词创建多个旁注窗口，各窗口的 `SelectedText`、输入框草稿、`ThreadId` 与流式输出互不串流，并自动错开窗口坐标避免完全重叠。
- **异常恢复**：若本机 App Server 子进程意外退出，后台会自动拉起并在下一轮提问时自动重锚定上下文继续对话。

## 6. 本地历史管理窗口（`Ctrl+Alt+H`）

随时按 **`Ctrl+Alt+H`**（或点击旁注窗口上的 **「历史」** 按钮，或运行 `SelectionProbe.exe --show-history`）打开本地历史窗口（`HistoryWindow`）：

- **账号隔离**：仅展示当前登录账号作用域指纹下的历史旁注（不保存明文邮箱或 Token）。
- **快速检索与筛选**：支持按关键词实时检索引用原文、提问与回答内容，以及按日期范围筛选。
- **完整生命周期管理**：
  - **打开/恢复**：双击或点击打开历史旁注，自动还原完整多轮记录与原 `ThreadId` 继续追问；
  - **重命名与归档**：为重要旁注自定义标题或移入归档视图；
  - **软删除与回收站**：误删可从回收站一键恢复；
  - **确认永久删除**：支持带明确二次确认的物理删除；
  - **在线备份**：基于 SQLite Online Backup API 导出一致性快照，备份文件位于 `%USERPROFILE%\.context-notes-native\backups\`。
